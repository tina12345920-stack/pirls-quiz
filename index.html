👋 老師使用說明
  1. 依序完成下方 STEP1～STEP3：選測驗對象、設定各題型題數、選想要的輸出格式。
  2. STEP4 用手機相機拍下文章，或直接上傳圖片。
  3. 按下「生成測驗」，系統會自動讀圖辨識並依設定出題。
  4. 完成後可直接產生專屬連結與 QR Code 給學生作答，並隨時查看學生成績。

⚠ 點開即可直接使用，無需輸入任何金鑰或付費設定。

這份測驗要給誰？

先設定測驗對象，之後的出題難度與用字會依此調整。

選擇每種層次要出幾題

依照 PIRLS 閱讀理解四層次分配題數，設為 0 代表不出該類型的題目。
